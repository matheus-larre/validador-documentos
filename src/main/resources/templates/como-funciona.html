Do documento à decisão, em segundos

O problema

Conferir documentos à mão no cadastro é lento, sujeito a erro e gera retrabalho para a equipe de backoffice.

A solução

O sistema lê o documento, a IA extrai os dados e regras objetivas decidem: aprovado ou reprovado, sempre com o motivo.

O fluxo

Cada etapa tem uma tecnologia responsável.

  1. Envio

    O analista envia o PDF ou a imagem.

    PDF · PNG · JPG

  2. Leitura

    O OCR transforma a imagem em texto.

    Tesseract

  3. Interpretação

    A IA organiza o texto em dados estruturados.

    Gemini

  4. Regras

    As regras de negócio conferem cada dado.

    Java · Spring Boot

  5. Resultado

    A decisão fica salva e disponível para consulta.

    PostgreSQL

Como usar

1

Envie o arquivo

Em Enviar documento, escolha o tipo (comprovante de residência ou RG/CNH) e arraste o arquivo (PDF, PNG ou JPG, até 10MB).

2

Aguarde alguns segundos

O sistema lê o documento, extrai os dados com IA e aplica as regras automaticamente.

3

Confira o resultado

Veja o selo, o checklist com o motivo de cada regra e os dados. Tudo fica no Histórico.

Regras de validação

Cada tipo de documento tem as suas regras. Ele só é aprovado se todas forem atendidas.

Comprovante de residência

  • Documento legívelO OCR reconhece texto suficiente no arquivo.
  • Nome identificadoO titular do comprovante foi encontrado.
  • CPF válido11 dígitos, não repetidos, com os dígitos verificadores corretos (módulo 11).
  • Endereço identificadoO endereço do titular foi encontrado.
  • CEP válidoCEP com 8 dígitos.
  • Estado válidoUma das 27 UFs brasileiras.
  • Emissão recenteEmitido há no máximo 90 dias e sem data no futuro.

Documento de identificação (RG ou CNH)

  • Documento legívelO OCR reconhece texto suficiente no arquivo.
  • Nome identificadoO nome completo do titular foi encontrado.
  • CPF válidoMesma conferência do módulo 11.
  • Número do documentoNúmero do RG ou registro da CNH encontrado.
  • Data de nascimento válidaPresente, não futura e plausível.
  • Titular maior de idade18 anos completos, por ser cadastro de cliente.
  • Dentro da validadeA CNH não pode estar vencida. O RG não tem validade.

Para outros sistemas: API REST

O mesmo fluxo da tela, com respostas em JSON.

POST/api/documentosenvia um documento (multipart: tipo + arquivo) → 201
GET/api/documentoslista o histórico resumido
GET/api/documentos/{id}detalhe completo, ou 404

Pronto para validar?

Use apenas documentos de teste: os dados enviados ficam salvos no histórico.
